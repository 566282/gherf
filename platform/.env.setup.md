# Environment Configuration

## Required Environment Variables

### Supabase Configuration
```bash
VITE_SUPABASE_URL=https://your-project-ref.supabase.co
VITE_SUPABASE_ANON_KEY=your-public-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-server-only-service-role-key
```

### Application Environment
```bash
VITE_APP_ENV=development|staging|production
VITE_AUTH_BOOTSTRAP_SUPER_ADMIN_USER_ID=001007
VITE_AUTH_BOOTSTRAP_SUPER_ADMIN_EMAIL=walterdozie7@gmail.com
AUTH_BOOTSTRAP_SUPER_ADMIN_USER_ID=001007
AUTH_BOOTSTRAP_SUPER_ADMIN_EMAIL=walterdozie7@gmail.com
VITE_AUTH_ADVERTISER_EMAILS=advertiser@example.com
AUTH_ADVERTISER_EMAILS=advertiser@example.com
```

### Optional Trusted Email Role Mapping

Use comma-separated email lists to force role resolution for accounts created directly in Supabase Auth (without the admin-managed metadata path).

Super admin fallback is intentionally stricter: it only applies when both the bootstrap user id and bootstrap email match.

```bash
VITE_AUTH_BOOTSTRAP_SUPER_ADMIN_USER_ID=00000000-0000-0000-0000-000000000000
VITE_AUTH_BOOTSTRAP_SUPER_ADMIN_EMAIL=walterdozie7@gmail.com
AUTH_BOOTSTRAP_SUPER_ADMIN_USER_ID=00000000-0000-0000-0000-000000000000
AUTH_BOOTSTRAP_SUPER_ADMIN_EMAIL=walterdozie7@gmail.com
VITE_AUTH_CAMPAIGN_MANAGER_EMAILS=manager1@example.com
VITE_AUTH_MODERATOR_EMAILS=mod1@example.com
VITE_AUTH_ADVERTISER_EMAILS=brand1@example.com,brand2@example.com
AUTH_CAMPAIGN_MANAGER_EMAILS=manager1@example.com
AUTH_MODERATOR_EMAILS=mod1@example.com
AUTH_ADVERTISER_EMAILS=brand1@example.com,brand2@example.com
```

Use the same values for VITE_* and AUTH_* so browser routing and server-side admin authorization stay consistent.

## Setup Instructions

1. Create a Supabase project at https://supabase.com
2. Copy your project's URL and anon key to `.env.local`
3. Run database migrations:
   ```bash
   npm run db:migrate
   ```
4. Seed initial data (optional):
   ```bash
   npm run db:seed
   ```

## Development

```bash
cp .env.example .env.local
npm install
npm run dev
```

The app will run at http://localhost:5173

## Production Build

```bash
npm run build
npm run preview
```

## Deployment to Netlify

1. Connect your GitHub repo to Netlify
2. Set environment variables in Netlify dashboard
3. Build command: `npm run build`
4. Publish directory: `dist`
5. Deploy

## Security Notes

- Never commit `.env.local`
- The `VITE_SUPABASE_ANON_KEY` is public; it's your project's read-only key
- Keep `SUPABASE_SERVICE_ROLE_KEY` on the server only; it must never be exposed to the browser
- All sensitive operations are protected by Supabase RLS policies
- Admin actions require `super_admin` role, enforced at database level
